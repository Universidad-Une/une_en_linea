# Despliegue del sitio y API de inscripción

La arquitectura vigente usa un único `dist/` estático y dos procesos independientes administrados por PM2: API y worker.

Sigue [Despliegue con PM2](pm2.md) para configuración local, archivos del VPS, entorno, Nginx, arranque y actualizaciones. Las plantillas systemd anteriores fueron retiradas.
